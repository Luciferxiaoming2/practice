# 训练项目一：ENDPAGE 熵析云枢打卡系统

## 项目概述

熵析云枢打卡系统是一套跨平台考勤管理解决方案，包含 Web 管理端与 Flutter 移动双端（iOS / Android）。系统支持人脸识别、地理围栏、时间段限制等多维度打卡验证方式。

---

## 技术栈

| 端 | 技术 |
|---|---|
| Web 管理端 | Next.js + React（响应式，手机 + 电脑 UI 适配） |
| 移动端 | Flutter（iOS + Android） |
| 后端 | 待定（建议 RESTful API） |
| 人脸识别 | 待定（可接入第三方 SDK） |

---

## 功能模块

### 1. Web 管理端

#### 账户管理
- 新建账户（填写基本信息、分配角色）
- 查看 / 编辑账户信息
- 重置密码
- 重置人脸数据
- 账户状态管理（active / inactive）

#### 打卡规则配置
每个账户可单独配置打卡要求：
- 是否要求地点打卡
  - 若是：设置允许打卡的地理坐标及半径范围（米）
- 是否要求时间段打卡
  - 若是：设置允许打卡的时间窗口（开始时间 ~ 结束时间）
- 是否要求人脸识别验证

#### UI 适配
- 响应式布局，兼容桌面浏览器与手机浏览器

---

### 2. Flutter 移动端（iOS + Android）

#### 首次登录流程
1. 使用管理端分配的账号 + 初始密码登录
2. 强制要求修改密码
3. 录入人脸数据
4. 授权定位权限（如账户规则要求）
5. 完成以上步骤后，账户状态标记为 **active**

#### 日常打卡流程
根据账户配置的规则，打卡时自动校验：
- 人脸识别（活体检测）
- GPS 定位（判断是否在允许范围内）
- 时间段验证（判断是否在允许时间窗口内）

#### 其他功能
- 打卡记录查看
- 个人信息查看
- 修改密码

---

## 账户状态流转

```
新建账户（inactive）
    ↓ 首次登录 + 录入人脸 + 修改密码
active（可正常打卡）
    ↓ 管理员重置人脸 / 密码
需重新完成对应步骤
```
