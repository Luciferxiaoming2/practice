# 常见问题排查

## 1. 移动端连接超时 / 无法连接后端

**现象**：移动端登录或操作时提示连接超时。

**原因**：真机无法通过 `127.0.0.1` 直接访问电脑的后端服务（localhost 指向手机自身）。

**解决方案**：

方案一（推荐）：使用 adb 端口转发
```bash
adb reverse tcp:8000 tcp:8000
```
移动端 API 地址保持 `http://127.0.0.1:8000`，通过 USB 隧道访问电脑后端。

方案二：使用局域网 IP
1. 确保手机和电脑在同一 Wi-Fi 下
2. 修改 `mobile/lib/core/config.dart` 中 `apiBaseUrl` 为电脑局域网 IP
3. 后端启动时加 `--host 0.0.0.0` 监听所有网卡
4. Windows 防火墙需放行 8000 端口（需管理员权限）：
```bash
netsh advfirewall firewall add rule name="ENDPAGE-Backend" dir=in action=allow protocol=TCP localport=8000
```

**注意**：每次重新插拔 USB 后需重新执行 `adb reverse`。

## 2. 人脸录入失败

**现象**：拍照采集成功，点击"完成录入"后提示"录入失败，请重试"。

**可能原因及排查**：

### 2.1 后端进程残留导致请求打到旧进程

**现象**：后端日志中看不到 `/face/enroll` 请求。

**原因**：端口 8000 上有多个进程监听（旧进程未完全退出），adb reverse 转发的请求可能打到旧进程。

**排查**：
```bash
netstat -ano | grep ":8000.*LISTENING"
```
如果出现多个 PID，说明有残留进程。

**解决**：
```bash
# 杀掉所有占用 8000 端口的进程
taskkill /F /FI "IMAGENAME eq python.exe"
# 等待几秒后重新启动
cd backend
uvicorn app.main:app --host 0.0.0.0 --port 8000 --reload
```

### 2.2 人脸模型下载失败（已修复）

**历史问题**：早期版本依赖从 GitHub 下载 ONNX 模型，国内网络环境下载失败导致人脸服务不可用。

**已修复**：现已改为 OpenCV 内置 Haar Cascade + LBP 直方图特征方案，无需下载外部模型。

### 2.3 未检测到人脸

**现象**：后端返回 400 "未检测到人脸，请确保光线充足且面部清晰"。

**排查**：确保拍摄时光线充足、面部正对摄像头、无遮挡。

## 3. 启动后移动端白屏几秒

**现象**：App 启动后显示白屏，几秒后才出现界面。

**原因**：`auth.init()` 在 `runApp()` 之前执行，会从 secure storage 读 token 并发网络请求获取用户信息，阻塞了 UI 渲染。

**已修复**：将 `auth.init()` 改为异步执行，启动时先显示品牌加载页，初始化完成后再进入主界面。

---

## 4. 人脸录入成功后无法返回首页

**现象**：人脸录入提示成功，但页面停留在录入页面不跳转。

**原因**：GoRouter 的 redirect 逻辑未覆盖 `/setup/face` 和 `/setup/password` 页面，从 setup 页面跳转到 `StatefulShellRoute` 内的 `/home` 时可能失效。

**已修复**：
1. 路由 redirect 新增规则：已完成设置的用户不再停留在 setup 页面，自动跳转 `/home`
2. 导航前增加延迟，确保 Provider 状态更新传播到路由层

---

## 5. Windows 下 stop.bat 在 Git Bash 中执行失败

**现象**：在 Git Bash 中运行 `stop.bat` 报错 "The system cannot find the batch label specified"。

**原因**：bat 脚本的 `call :label` 语法在 Git Bash 的 cmd 兼容层中有 bug。

**解决**：直接在 Windows CMD 或 PowerShell 中双击运行 `stop.bat`，或手动杀进程：
```bash
# 查看占用端口的进程
netstat -ano | grep ":8000\|:3000" | grep LISTENING
# 杀掉对应 PID
taskkill /F /PID <PID>
```
