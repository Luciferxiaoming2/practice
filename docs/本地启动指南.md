# 本地启动指南

> 本文档适用于 **Windows 本地开发环境**，用于启动熵析云枢打卡系统的 Web 前端和后端服务。

## 快速启动

双击项目根目录的 `start.bat`，脚本会自动完成以下操作：

1. 检查 Node.js 和 Python 虚拟环境
2. 检测端口占用并自动处理冲突
3. 启动后端 API 服务（FastAPI + Uvicorn）
4. 启动前端 Web 服务（Next.js）
5. 等待服务就绪后自动打开浏览器

## 环境要求

| 依赖 | 说明 |
|------|------|
| Node.js | ≥18，需在系统 PATH 中 |
| Python 虚拟环境 | 路径：`D:\uv\venvs\practice` |
| 后端依赖 | 首次需在虚拟环境中执行 `pip install -r backend/requirements.txt` |
| 前端依赖 | 脚本会自动检测并执行 `npm install`（首次） |

## 默认端口

| 服务 | 端口 | 地址 |
|------|------|------|
| 后端 API | 8000 | http://localhost:8000/docs （Swagger 文档） |
| 前端 Web | 3000 | http://localhost:3000 |

如果默认端口被占用，脚本会尝试自动释放；若释放失败，会自动分配下一个可用端口并在终端中显示实际端口号。

## 手动启动

如果不想使用一键脚本，可以分别启动：

**后端：**

```bash
cd D:\practice\one\backend
D:\uv\venvs\practice\Scripts\activate.bat
uvicorn app.main:app --host 127.0.0.1 --port 8000 --reload
```

**前端：**

```bash
cd D:\practice\one\web
npm run dev -- --port 3000
```

## 停止服务

双击项目根目录的 `stop.bat` 即可一键停止所有服务。

`stop.bat` 会自动读取 `start.bat` 启动时写入的 `.endpage.lock` 文件，获取实际使用的端口号（包括因冲突而切换的端口），精准关闭对应进程并清理锁文件。

也可以手动关闭弹出的两个终端窗口（标题为 `ENDPAGE-Backend` 和 `ENDPAGE-Frontend`）来停止服务。

## 常见问题

**Q: 启动后前端页面空白或报 CORS 错误**
A: 确保通过 `http://localhost:3000` 而非 `http://127.0.0.1:3000` 访问前端。后端 CORS 已配置允许 localhost 和 127.0.0.1 两种地址。

**Q: 提示 "后端启动失败"**
A: 检查后端终端窗口的错误信息，通常是依赖未安装。在虚拟环境中执行：
```bash
pip install -r backend/requirements.txt
```

**Q: 提示 "npm install 失败"**
A: 检查网络连接，或尝试切换 npm 镜像：
```bash
npm config set registry https://registry.npmmirror.com
```
