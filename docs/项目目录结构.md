# 熵析云枢 — 项目目录结构

## 整体架构

```
one/
├── backend/          # 后端 API（FastAPI + SQLite）
├── web/              # Web 管理端（Next.js + Tailwind + shadcn/ui）
├── mobile/           # 移动端（Flutter）
├── docs/             # 项目文档
├── test/             # 集成测试
├── design-skill/     # 设计规范文档
├── .github/          # CI/CD 配置
├── start.bat         # 一键启动脚本（Windows）
├── stop.bat          # 一键停止脚本（Windows）
├── pyproject.toml    # Python 项目配置
├── vercel.json       # Vercel 部署配置
└── README.md
```

三端共用同一个后端 API 和 SQLite 数据库：

```
Web 管理端 (:3000)  ──┐
                      ├──→  FastAPI 后端 (:8000)  ──→  SQLite (endpage.db)
移动端 (Flutter)  ────┘
```

## backend/ — 后端 API

基于 FastAPI + SQLAlchemy + SQLite，提供 RESTful API。

```
backend/
├── main.py                     # 入口文件
├── requirements.txt            # Python 依赖
├── pyproject.toml              # 项目配置
├── create_admin.py             # 管理员创建脚本
├── endpage.db                  # SQLite 数据库文件
└── app/
    ├── main.py                 # FastAPI 应用初始化、路由注册、CORS 配置
    ├── core.py                 # JWT 鉴权、密码加密、权限校验
    ├── database.py             # 数据库连接与会话管理
    ├── seed.py                 # 初始数据填充（角色、权限）
    ├── models/                 # SQLAlchemy 数据模型
    │   ├── user.py             #   用户模型（账号、打卡规则、人脸状态）
    │   ├── checkin.py          #   打卡记录模型
    │   └── role.py             #   角色与权限模型（多对多）
    ├── routers/                # API 路由
    │   ├── auth.py             #   登录 / 注册（POST /auth/login, /auth/register）
    │   ├── users.py            #   用户 CRUD（GET/POST/PATCH/DELETE /users）
    │   ├── checkins.py         #   打卡（POST /checkins, GET /checkins）
    │   └── roles.py            #   角色权限管理（CRUD /roles）
    └── schemas/                # Pydantic 请求/响应模型
        ├── auth.py             #   LoginRequest, RegisterRequest, Token
        ├── user.py             #   UserCreate, UserUpdate, UserOut
        ├── checkin.py          #   CheckInCreate, CheckInOut
        └── role.py             #   RoleCreate, RoleUpdate, RoleOut
```

### API 端点概览

| 模块 | 端点 | 说明 |
|------|------|------|
| 认证 | `POST /auth/login` | 登录，返回 JWT |
| 认证 | `POST /auth/register` | 公开注册 |
| 用户 | `GET/POST/PATCH/DELETE /users` | 用户管理（管理员） |
| 用户 | `POST /users/{id}/reset-password` | 重置密码 |
| 打卡 | `POST /checkins/` | 创建打卡（服务端验证位置/时间） |
| 打卡 | `GET /checkins/` | 查询记录（支持日期筛选） |
| 角色 | `GET/POST/PATCH/DELETE /roles` | 角色权限 CRUD |

## mobile/ — 移动端

基于 Flutter + Provider + GoRouter，支持 Android/iOS。

```
mobile/
├── pubspec.yaml                # Flutter 依赖配置
├── analysis_options.yaml       # Dart 代码分析配置
└── lib/
    ├── main.dart               # 入口：初始化高德SDK、Provider、路由
    ├── core/                   # 核心模块
    │   ├── config.dart         #   配置（API 地址、高德 Key）
    │   ├── api.dart            #   Dio HTTP 客户端（JWT 拦截器）
    │   ├── router.dart         #   GoRouter 路由（底部导航 + 鉴权重定向）
    │   ├── theme.dart          #   Material 3 主题定义
    │   └── local_store.dart    #   本地存储（离线回退）
    ├── models/                 # 数据模型
    │   ├── user.dart           #   用户模型（fromJson / toJson / copyWith）
    │   └── checkin.dart        #   打卡记录模型
    ├── services/               # 服务层（API 调用封装）
    │   ├── auth_service.dart   #   认证服务（登录/注册/获取用户/改密码）
    │   ├── checkin_service.dart #   打卡服务（创建打卡/查询记录）
    │   └── location_service.dart # 高德定位服务封装
    ├── providers/              # 状态管理（ChangeNotifier）
    │   ├── auth_provider.dart  #   认证状态（JWT 存储/解析/离线回退）
    │   └── checkin_provider.dart # 打卡状态（打卡/历史/日期筛选）
    ├── screens/                # 页面
    │   ├── shell_screen.dart   #   底部导航壳（打卡/记录/我的）
    │   ├── auth/
    │   │   ├── login_screen.dart       # 登录
    │   │   ├── register_screen.dart    # 注册
    │   │   ├── setup_password_screen.dart # 首次设置密码
    │   │   └── setup_face_screen.dart  # 人脸录入
    │   ├── checkin/
    │   │   ├── home_screen.dart        # 打卡首页（定位+打卡按钮）
    │   │   └── history_screen.dart     # 打卡记录（日期筛选）
    │   └── profile/
    │       └── profile_screen.dart     # 个人中心（信息/改密码）
    └── widgets/                # 可复用组件
        ├── shared_widgets.dart #   PrimaryButton、StepIndicator
        ├── app_text_field.dart #   统一输入框
        └── empty_state.dart   #   空状态占位
```

### 移动端关键依赖

| 包名 | 用途 |
|------|------|
| `dio` | HTTP 客户端 |
| `provider` | 状态管理 |
| `go_router` | 路由导航 |
| `flutter_secure_storage` | JWT 安全存储 |
| `shared_preferences` | 本地缓存 |
| `amap_flutter_location` | 高德定位 SDK |
| `geolocator` | GPS 定位 |
| `permission_handler` | 权限请求 |
| `image_picker` | 相机拍照（人脸录入） |

### 移动端页面流程

```
登录/注册 → 首次设置密码 → 人脸录入 → 主页（底部导航）
                                         ├── 打卡（定位+打卡）
                                         ├── 记录（历史+筛选）
                                         └── 我的（信息+改密码）
```

## 本地开发启动

```bash
# 1. 启动后端
cd backend && uvicorn app.main:app --host 0.0.0.0 --port 8000

# 2. 启动 Web 管理端
cd web && npm run dev

# 3. 启动移动端（USB 连接手机）
adb reverse tcp:8000 tcp:8000
cd mobile && flutter run -d <设备ID>
```

或直接使用一键脚本：`start.bat`
