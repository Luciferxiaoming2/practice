## 五、跨端协作问题

| 问题 | 涉及端 | 说明 |
|------|--------|------|
| 打卡接口未实现 | 后端 ↔ 移动端 | 移动端已调用 `POST /checkins/`，但后端无此路由，打卡会 404 |
| 接口无鉴权 | 后端 ↔ Web | 所有 `/users/` 接口无需 Token 即可访问 |
| 打卡记录两端均未开发 | 全端 | 后端无查询接口，Web/移动端无展示页面 |
| 打卡规则无配置入口 | 后端 ↔ Web | 后端 PATCH 接口支持更新规则字段，但 Web 端未提供配置 UI |

## 六、下一步开发建议（按优先级排序）

### P0 — 阻塞性问题
1. **后端：实现打卡路由** `POST /checkins/` 和 `GET /checkins/`，解除移动端打卡 404
2. **后端：接口鉴权**，为 `/users/` 路由添加 Token 校验，区分管理员和普通用户权限
3. **移动端：修复人脸预览 Bug**，`Image.network()` → `Image.file()`

### P1 — 核心功能补全
4. **Web：打卡记录页**，展示全部用户打卡历史，支持筛选和分页
5. **Web：打卡规则配置 UI**，在账户管理中增加位置/时间/人脸规则编辑
6. **移动端：打卡记录页**，展示当前用户的打卡历史

### P2 — 体验优化
7. **后端：管理员权限校验**
8. **Web：系统设置页**
9. **Web：响应式移动端适配**
10. **移动端：人脸识别 SDK 接入**
